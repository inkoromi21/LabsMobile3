# Лабораторная работа № 3

## Что задано

Изучить основы Jetpack Compose, выполнить практическое приложение Happy Birthday и четыре контрольных задания.

## Что сделано

Подготовлены пять отдельных Android-проектов на Kotlin: HappyBirthday, ComposeArticle, TaskManager, ComposeQuadrant и MyInformation. Использованы Text, Image, Column, Row, Box, Modifier и строковые ресурсы.
