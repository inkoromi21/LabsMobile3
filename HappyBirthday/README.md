# Happy Birthday

## Что задано

Создать поздравление с подписью поверх фонового изображения. Использовать Compose, строковые ресурсы, масштабирование Crop и прозрачность фона 0.5.

## Что сделано

Созданы GreetingText и GreetingImage. Текст и подпись размещены через Column, фон и текст объединены в Box. Изображение заполняет экран, строки находятся в strings.xml.
